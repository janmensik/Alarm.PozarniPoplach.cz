## 2023-10-27 - Use getNoCalcRows for specific Modul inheriting queries
**Learning:** In MySQL-backed PHP applications, specifically those utilizing `Janmensik\Jmlib\Modul`, using `->get()` automatically appends `SQL_CALC_FOUND_ROWS` behind the scenes. This causes MySQL to evaluate all matching rows for the total count even when fetching a single record (`LIMIT 1`). For frequent single-record queries on large datasets, this constitutes a major performance regression and high database load.
**Action:** Always replace `->get()` with `->getNoCalcRows()` (or pass `true` as the 5th parameter to `get()`) when retrieving a single row or explicitly avoiding pagination in Modul subclasses to prevent expensive full-table scans.
